本版本修复桌面歌词长句被窗口左右截断的问题，包含 v0.18-lyrics.3 的全部修复。

## 桌面歌词

- 点亮时整行会放大 1.4 倍。`Transform.scale` 只影响绘制、不影响布局，之前仍按窗口全宽排版，长句放大后会被推出窗口，左右两侧被截断。现在先按缩放后的可见宽度排版，再用 `FittedBox` 把过长的单行缩进窗口：短句保持原字号，长句自动变小，始终完整显示。
- 桌面歌词冒烟样例改为长句，CI 截图可以直接检查换行与截断是否回归。
- 上一版的修复保持不变：子窗口先渲染再带重试连接插件（release 不再空白）、透明背景、锁定点击穿透、工具窗口不占任务栏、Android release 启动闪退修复。

## 验证
