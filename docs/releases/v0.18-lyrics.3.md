本版本修复 Windows 桌面歌词在 release 包中不显示，以及 Android release 包启动即闪退。

## 桌面歌词（Windows）

- 子窗口在 `runApp` 之前就调用桌面歌词插件。release 包启动比 debug 快，插件注册尚未完成时会抛 `MissingPluginException`，窗口一直空白隐藏，主窗口超时后还会把开关复位。现在先渲染第一帧，再带重试连接父窗口；显示前先送快照，不再出现空白置顶窗。
- 恢复透明背景；锁定后点击穿透不会再让歌词整窗消失；子窗口不占任务栏、不出现在 Alt+Tab。
- 子窗口初始化失败会写 `%TEMP%\flutify-desktop-lyrics.log`，方便定位。
- 主窗口的就绪超时改为 12 秒，且不会被每秒的状态推送续命；旧引擎迟到的就绪消息不会误判新窗口。

## Android

- AGP 9 默认开启 R8 的 `strictFullModeForKeepRules`，`-keep class X` 不再隐式保留无参构造函数。Room 的 `WorkDatabase_Impl.<init>()` 被删掉，WorkManager 在启动时反射实例化失败，release 包直接闪退。关闭该选项，恢复 AGP 8 的保留语义。
- 本次 APK 仍使用 CI debug 密钥签名，不是固定发布证书；从其他证书签名的版本升级需要先卸载旧版。

## 验证

- Windows release 本地实机验证：歌词显示、透明悬浮、锁定点击穿透、重启后保持开启。
- GitHub Actions 全平台构建与桌面歌词冒烟测试通过。Android 未做真机验证；修复方式与上游 issue #65 对应的 PR #66 一致。
