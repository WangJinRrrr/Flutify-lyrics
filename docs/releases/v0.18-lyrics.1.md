本版本在 Flutify v0.18 上增加桌面歌词，并由 GitHub Actions 构建后发布。校验和见 `SHA256SUMS.txt`。

## 来源

基于 [Flutify](https://github.com/is-hp-is-mad/Flutify) 提交 `89c55a875a7f532c090abd95b7b551f2ce16e5a3`（v0.18，MIT）。原许可证和署名保留。桌面歌词的视觉用 Dart 重写，参考来源见仓库 `NOTICE`。

## 桌面歌词

- 无边框、置顶、透明的独立窗口，显示当前行。
- 进度沿用本机播放和 Spotify Connect 远程进度；远程播放会加上设置里的歌词提前量。
- 歌词沿用应用内的获取逻辑。没有逐字时间时整行点亮，不假造逐字。
- 第一句前显示歌名；载入中、无歌词、未同步各有提示；空行和 ♪ 显示为间奏。
- 暂停时停住，切歌时先清空。
- 未锁定可以拖动，位置记在 `ui_desktop_lyrics_bounds`。锁定后点击穿透到后面的窗口。
- 开关和锁定在设置页「桌面歌词」、桌面歌词窗口，以及歌词面板。
- Android 不创建这个窗口。

## 安装包

- Windows x64：`*-windows-x64-setup.exe` 安装版，以及 `*-windows-x64.zip` 便携版。在 `windows-latest` 上用 `flutter build windows --release` 构建，安装包由仓库里的 Inno Setup 脚本产出。没有做代码签名，也没有 Windows ARM64 包。
- Android：按 ABI 拆分的 APK 和通用包，`flutter build apk --release`。没有上游签名密钥时使用 debug 密钥，构建说明会写明这次实际用的是哪一种。debug 签名会被系统视为未知来源，也不能覆盖用其他证书安装的旧版本。
- macOS：未做 Developer ID 签名和 Apple 公证的测试 ZIP。
- Linux x64：实验性 `.deb` 和 tar.gz。

## 未验证

这些包只经过 GitHub Actions 的构建和仓库里的产物校验。没有在 Windows、Android、macOS 或 Linux 上做实机安装和播放验证，也没有打开桌面歌词窗口核对置顶、透明、拖动和点击穿透。
