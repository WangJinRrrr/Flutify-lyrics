修复 v0.18-lyrics.1 打开桌面歌词后闪退，并且下次启动也会闪退的问题。校验和见 `SHA256SUMS.txt`。

## 修复

桌面歌词是同一个进程里的第二个 Flutter 引擎。v0.18-lyrics.1 在这个子引擎上又注册了主程序的全部插件，包括 WebView2、系统托盘和全局热键。Windows 上这次重复初始化会把整个进程打崩。开关已经写入偏好，所以下次启动还会再建窗口，继续闪退。

现在子窗口只注册 `window_manager` 和 `screen_retriever`。Windows 上不再通过 window_manager 改透明、无边框和置顶（那些调用会把进程打成访问冲突）；无边框和置顶改由子窗口自己的 HWND 设置，主窗口不动。子窗口创建失败会记日志并把开关关掉，已经打开过开关的旧偏好在升级后可以正常启动。

## 桌面歌词样式

呼吸、入场离场、点亮缩放和双层光晕的数值移植自 Folia-major classic（AGPL-3.0，提交 `a44758bbc02929225ca7304b5a4c4580d7b4e87b`）。只包含这些样式数值。仓库许可证仍是 MIT，派生部分的说明见 NOTICE。

## 安装包与限制

- Windows x64 / ARM64：安装版和便携 zip，没有代码签名。
- Android：debug 密钥签名（本仓库没有上游发布证书），不能覆盖其他证书安装的旧版本。
- macOS：未做 Developer ID 签名和 Apple 公证。
- Linux x64：实验性 `.deb` 和 tar.gz。
- 没有在各系统上做完整播放实测。Linux 桌面和 Windows CI 冒烟测过桌面歌词窗口能单独打开且主窗口还在。
