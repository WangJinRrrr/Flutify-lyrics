本版本修复桌面歌词在锁定 / 未锁定两种状态下位置不一致的问题，并停止在 CI 构建 macOS / Linux。

## 桌面歌词

- 控制按钮以前和歌词放在同一个 `Column` 里。锁定后按钮行被整行移除，歌词也跟着上移，看起来像换了个位置。现在按钮改为叠在窗口右上角的浮层，歌词始终在窗口正中，锁定前后位置完全一致。
- 长句自动缩放保持不变（v0.18-lyrics.4 已修复）：短句保持原字号，长句完整缩进窗口，不再左右截断。
- 实测在 500px 窄窗口下，长句在锁定 / 未锁定两种状态位置一致、整句完整显示。

## CI

- `Build` 与 `Self-test` 不再构建 macOS / Linux，只保留 Android 与 Windows x64 / ARM64，发布页只上传 Android APK 和 Windows 安装版 / 便携版。
- 发布流程仍会校验全部产物并生成 `SHA256SUMS.txt`。

## 验证

- Windows release 本地实机验证：长句完整显示，锁定 / 未锁定位置一致，透明、置顶、点击穿透正常。
- GitHub Actions 在 Android / Windows 上构建与桌面歌词冒烟测试。Android 未做真机验证。
